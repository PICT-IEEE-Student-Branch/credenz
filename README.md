# Credenz Website

Code for **[credenz.co.in](https://www.credenz.co.in/)**, the website of **Credenz**, PISB's annual technical festival. It holds the frontend and backend, with one folder per year.

| Year | Frontend | Backend |
|---|---|---|
| **2026**: *Warping Realities* | 🔜 [`2026/frontend/`](2026/frontend/) | 🔜 [`2026/backend/`](2026/backend/) |

**Where do I push?** Put this year's site in `2026/frontend/` and `2026/backend/`. Next year's goes in `2027/`. To deploy from this repo (Vercel/Netlify), set the *Root Directory* to that folder.
Never commit `.env` files, API keys, database URLs, or registration and payment data.

Each Credenz event has its own repo: [xodia](https://github.com/PICT-IEEE-Student-Branch/xodia) · [nth](https://github.com/PICT-IEEE-Student-Branch/nth) · [datawiz](https://github.com/PICT-IEEE-Student-Branch/datawiz) · [enigma](https://github.com/PICT-IEEE-Student-Branch/enigma) · [reverse-coding](https://github.com/PICT-IEEE-Student-Branch/reverse-coding) · [web-weaver](https://github.com/PICT-IEEE-Student-Branch/web-weaver) · [merge-conflict](https://github.com/PICT-IEEE-Student-Branch/merge-conflict) · [cretronix](https://github.com/PICT-IEEE-Student-Branch/cretronix) · [b-plan](https://github.com/PICT-IEEE-Student-Branch/b-plan) · [wallstreet](https://github.com/PICT-IEEE-Student-Branch/wallstreet) · [roboliga](https://github.com/PICT-IEEE-Student-Branch/roboliga)
