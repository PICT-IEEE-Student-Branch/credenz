# Credenz — PISB's Annual Technical Fest

**Credenz** is the flagship annual technical festival of the **PICT IEEE Student Branch (PISB)**, where participants discover their talents across numerous events. It runs tech and non-tech events, from coding and ML to electronics, robotics, puzzles, business and stock-market simulation. This repository is the hub: one place to find every event and its material, edition by edition.

🌐 [credenz.co.in](https://www.credenz.co.in/) · 🚀 [Credenz Tech Dayz (CTD) '26](https://ctd26.vercel.app/) · 📸 [Photos and memories](https://github.com/PICT-IEEE-Student-Branch/memories)

## Repository structure

```
credenz/
└── <year>/
    └── <event>/     rulebook, problem statements / question papers, solutions (after the event), notes for organisers
```

Code-heavy events get their **own repo**, named `<event>-credenz-<year>` (for example `xodia-credenz-2026`), which is linked from the tables above.

## Adding your event's material

1. Create `<year>/<event>/` and add the rulebook, problem statements or questions (and solutions once the event is over), plus a short `README.md` with notes for next year's organisers: what worked and what broke.
2. Change 🔜 to ✅ in the table above, with a link.
3. **Never commit** registration sheets, participant lists, leaderboards with names, participants' submissions, or anyone's contact details.

Ask a current PISB Tech head for write access.
